# Selected recording

The active recording is the user's supplied `azan.mp3`, approximately 180
seconds. It was converted, without trimming, to MPEG-2 MP3, 24 kHz stereo,
48 kbps for Alexa compatibility. The original is preserved at the project root;
the deployment copy is `audio/azan.mp3`. No license or artist information was
supplied, so this project does not claim ownership or apply a CC0 license to it.

The HTTPS endpoint exposes only the recording, not the app, private keys,
credentials, directory listing, or state database.

The same recording is initially used for all five prayers. Set `fajr_audio_url`
if a separate Fajr recording with the additional Fajr wording is desired.
The supplied file's wording has not been independently transcribed or verified.
